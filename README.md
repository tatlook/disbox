# disbox

## 它是什么

游戏。。。

## 如何编译

很简单，使用*make*命令就能编译了。
如果想要使用，就要使用*make release*命令即可在release目录下生成所有需要文件。
可以用*make run*测试运行。（或*make*+*./disbox*）

### 它需要什么

它需要make、gcc、gtk和libc。

## 如何使用

开局会随机生成一个表格，鼠标在表格上划过就会改变它的颜色。最后当表格上只有白色时结束，并输出统计信息。

## 为什么有这个软件

这本是一个五子棋软件。但在开发初期发生了一个大的不行的bug，从那里得到灵感而fork成了此游戏。
